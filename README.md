## Ravencraft 1.21
by RavTek

<p>Intro</p>

For those who don't know, Ravencraft 1.21 is a modification of EaglercraftX 1.8.8, a project by <a href="https://github.com/lax1dude/">lax1dude</a> and <a href="https://github.com/ayunami2000/">ayunami2000</a>. Ravencraft 1.21 simply changes some textures and changes the background of the title screen. Ravencraft 1.21 is licensed under the GNU General Public License v3.0.

<p>Why I created this</p>

I created this because some people don't have access to Planet Minecraft, the place where Ravencraft 1.21 is posted. RaveTek, the creator of RavenCraft 1.21, also didn't post the offline download version, so I put it here.
